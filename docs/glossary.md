# Глоссарий

[К документации](README.md)

Термины применяются во всех документах Takt. Английские идентификаторы обозначают те же понятия, что и русские названия.

| Термин | Определение |
| --- | --- |
| Takt | Веб-платформа для организации учебного процесса частных преподавателей, репетиторов и учеников. |
| Пользователь (User) | Человек, работающий с платформой. В Sprint 1 рассматриваются роли Teacher и Student. |
| Учётная запись (Account) | Данные, позволяющие идентифицировать пользователя при работе с платформой. Состав данных и связь учётной записи с ролями требуют согласования. |
| Преподаватель (Teacher) | Пользователь, который создаёт занятия для связанных с ним учеников и просматривает свои занятия в календаре. |
| Ученик (Student) | Пользователь, который просматривает свои предстоящие занятия и сведения о преподавателе. |
| Занятие (Lesson) | Запланированная учебная встреча, связывающая преподавателя, выбранного ученика и дату/время проведения в сценарии Sprint 1. Длительность и время окончания требуют согласования. |
| Расписание (Schedule) | Совокупность запланированных занятий, доступных пользователю в рамках его роли. Не подразумевает отдельную сущность хранения. |
| Предстоящее занятие (Upcoming lesson) | Занятие ученика, дата/время которого относится к будущему относительно момента проверки. Включение занятия ровно в текущий момент требует согласования: Q-02 в бизнес-правилах. |
| Календарный период (Calendar period) | Выбранный пользователем диапазон дат для просмотра календаря преподавателя. Правила включения границ и часовой пояс требуют согласования: Q-01 и Q-03. |
| Аутентификация (Authentication) | Проверка личности пользователя, позволяющая определить текущего пользователя. Конкретный механизм требует согласования. |
| Демонстрационные данные (Demo data) | Подготовленные данные для демонстрации и проверки сценариев. Точный состав требует согласования в рамках F-06. |
| Foundation | Задачи технической и организационной основы проекта с идентификаторами F-01–F-08. |
| Пользовательская история (User Story) | Описание результата для пользователя; в Sprint 1 используются US-01–US-03. |
| Story Points (SP) | Единица относительной оценки объёма работ. Общая оценка Sprint 1 — 93 SP; распределение по задачам в этих документах не задано. |

Открытые вопросы и подтверждённые ограничения приведены в [бизнес-правилах](requirements/business-rules.md).
