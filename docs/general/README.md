# Общая документация Takt

В этой директории находятся правила и понятия, общие для нескольких частей продукта.

## Документы

- [`product.md`](product.md) — роли, основные сущности, продуктовые правила и границы ответственности документации;
- [`api-conventions.md`](api-conventions.md) — общие правила внешнего API;
- [`acceptance-process.md`](acceptance-process.md) — общий процесс QA / Product Acceptance.

## Принцип организации

Общая документация должна содержать только то, что применяется сразу к нескольким Foundation / User Story.

Требования конкретного пользовательского сценария находятся в:

```text
docs/user-stories/us-XX/
```

Foundation описан отдельно в:

```text
docs/foundation/
```

Документация фиксирует ожидаемое поведение и обязательные ограничения, но не определяет внутреннюю техническую реализацию без необходимости.
