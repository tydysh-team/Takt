# Takt — общий контур прогресса и статистики

Документ фиксирует общие правила Epic 3 «Прогресс и статистика», используемые US-18–US-21.

## 1. Источники данных

Статистика строится на фактических данных:

- `Lesson`;
- attendance;
- Homework;
- Submission Attempt;
- результаты проверки.

Агрегаты не создают отдельный источник истины поверх исходных данных.

## 2. Объяснимость

Любой показатель должен быть объясним через исходные записи.

Непрозрачный AI-рейтинг ученика не используется.

## 3. Период

Статистические операции могут использовать `date_from` и `date_to`.

Текущий период должен быть явно понятен пользователю.

Если UI применяет период по умолчанию, он должен быть показан, а не скрыт.

## 4. Attendance

Неотмеченное attendance не считается автоматически `present` или `absent`.

Отменённые занятия не должны искусственно ухудшать посещаемость.

## 5. Homework

Допустимые объяснимые показатели:

- назначено;
- отправлено;
- проверено;
- просрочено;
- возвращалось на доработку.

При отсутствии данных деление на ноль не допускается.

## 6. Review metrics

Используются только сохранённые результаты проверки.

Отсутствующая оценка не подменяется нулём без отдельного продуктового правила.

## 7. Доступ

Teacher получает статистику только доступного ему Student.

Student видит только собственную статистику.

## 8. Согласованность

При одинаковом Student, периоде и исходных данных общие показатели Teacher и Student должны совпадать.

## 9. Empty / Error

Отсутствие данных является корректным состоянием.

API error должен отличаться от нулевых показателей.

## 10. Out of Scope Epic 3

- прогнозирование успеваемости;
- автоматические педагогические рекомендации;
- сравнение и ранжирование Students;
- публичные рейтинги;
- сложный BI;
- финансовая аналитика.
