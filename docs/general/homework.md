# Takt — общий контур домашних заданий

Документ фиксирует общие продуктовые правила Epic 2 «Домашние задания», используемые US-10–US-17.

## 1. Назначение

Контур связывает самостоятельную работу ученика с конкретной связкой `Teacher ↔ Student`.

```text
назначение → просмотр → сдача → проверка → результат
                                  ↓
                           возврат на доработку
                                  ↓
                              пересдача
```

Backend является источником истины для состояния задания, попыток сдачи и результата проверки.

## 2. Основные сущности

### Homework

Назначенное домашнее задание, связанное с конкретными Teacher и Student.

Пользовательски значимые данные:

- название;
- описание;
- срок выполнения `due_at`;
- материалы / вложения;
- актуальное состояние.

### Submission Attempt

Отдельная попытка сдачи Homework.

Содержит минимум:

- номер попытки;
- время отправки;
- комментарий Student при наличии;
- вложения при наличии;
- признак просроченной сдачи;
- результат проверки при наличии.

Повторная сдача создаёт новую попытку и не перезаписывает предыдущую.

### Review Result

Результат проверки конкретной попытки.

Может содержать оценку, комментарий Teacher и решение: принять работу либо вернуть на доработку.

## 3. Ownership

Teacher работает только с Homework и Submission своих Students.

Student видит и изменяет только собственные Homework и попытки.

Подмена `teacher_id`, `student_id`, `homework_id` или `submission_id` не должна давать доступ к чужим данным.

## 4. Lifecycle Homework

Используется продуктовая модель:

- `assigned` — задание назначено, актуальной отправленной попытки нет;
- `submitted` — актуальная попытка отправлена и ожидает проверки;
- `needs_revision` — актуальная попытка возвращена на доработку;
- `reviewed` — актуальная попытка проверена и принята.

`overdue` — вычисляемый признак, а не отдельный lifecycle-status.

Допустимые переходы:

```text
assigned → submitted → reviewed
             ↓
        needs_revision
             ↓
         submitted
```

## 5. Deadline

`due_at` является timezone-aware моментом времени.

Наступление deadline не удаляет Homework. Сдача после deadline может быть разрешена, но должна однозначно отражать факт просрочки.

## 6. Вложения

Продуктовая документация определяет принадлежность и доступность вложений.

Конкретное файловое хранилище, CDN, антивирус и внутренняя схема хранения не являются частью продуктового контракта.

## 7. Атомарность

Изменяющая операция либо завершается целиком, либо не оставляет частично применённое пользовательское состояние.

Frontend не показывает success до подтверждения Backend.

## 8. Общие состояния UI

- loading;
- empty;
- validation error;
- Backend / API error;
- success;
- disabled action из-за lifecycle или прав доступа.

Ошибка загрузки не отображается как корректный empty state.

## 9. API

Все операции соблюдают существующий [`api-conventions.md`](api-conventions.md):

- prefix `/api/v1`;
- authentication context;
- `snake_case`;
- timezone-aware date/time;
- единый error format.

## 10. Out of Scope Epic 2

Без отдельной User Story не входят:

- групповые задания;
- массовое назначение;
- чат внутри Homework;
- автоматическая проверка содержимого;
- AI-оценивание;
- сложные рубрики;
- публичные рейтинги;
- production-grade antivirus/CDN.
