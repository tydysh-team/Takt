# Документация Takt

Takt — веб-платформа для организации учебного процесса частных преподавателей, репетиторов и учеников. Этот раздел — точка входа в проектную и функциональную документацию.

В Sprint 1 создаётся техническая основа платформы и первый сквозной сценарий работы с расписанием. Документация описывает согласованный объём работ, а не подтверждает готовность реализации.

## Технологический стек

| Область | Технологии |
| --- | --- |
| Backend | Python 3.12, FastAPI, Pydantic |
| Работа с данными | PostgreSQL, SQLAlchemy, Alembic |
| Тестирование | pytest |
| Frontend | React, TypeScript |
| Локальное окружение | Docker, Docker Compose |
| Контроль версий | Git, GitHub |

Версии, кроме Python 3.12, здесь не зафиксированы. Указание технологии не означает, что её настройка уже выполнена.

## Поддержка документации

- Обновлять документы вместе с изменениями требований и поведения системы.
- Использовать термины из глоссария и ссылаться на стабильные идентификаторы бизнес-правил.
- Отделять подтверждённые требования Sprint 1 от будущих возможностей.
- Помечать нерешённые вопросы как `TBD / требуется согласование`; не выдавать предположения за решения.
- После согласования решения обновлять все связанные документы и проверять их согласованность.
- Использовать относительные ссылки внутри `/docs` и проверять их после перемещения файлов.
- Описывать API по единому формату; не фиксировать неподтверждённые пути, поля и механизмы как окончательные.
